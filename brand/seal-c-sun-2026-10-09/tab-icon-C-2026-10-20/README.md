# Tab icon, option C (founder's choice, 20 Oct 2026)

The browser-tab icon only. It is Seal C, sun version, drawn bolder for 16–48 px:
a thicker gold ring, a larger sun with eight rays, four dots in place of six, and a thin gold rim
so it holds up on light and dark tab bars. Everything larger (apple-touch icon, PWA icons,
header and footer seal) stays as the kit draws it.
